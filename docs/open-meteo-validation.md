# Open-Meteo 验证记录

2026-11-05 按用户决定切换供应商。公共 Forecast 和 Geocoding 端点不需要 Key、账户专属 Host 或签名头；应用用户也不需要账号。以下是本机实测的有限结论，不推断本机网络属于特定区域，不替代大陆宽带／移动／海外三组验收。

## 已取得的公开端点证据

- search 无 Key 调用成功；get?id=1809104 在 zh/en 下分别返回海淀与 Haidian。
- Forecast 无 Key 调用成功；返回 current_units 和 daily_units，温度 °C、相对湿度 %、风速 m/s、WMO 代码。
- 海淀样本每日日期为 2026-11-05 至 2026-11-11，共七天。此样本尚未覆盖午夜或所有代表地点，不将任务 1.3 整体标为完成。
- 当前时间是模型有效时刻；界面使用“获取于”。逐日聚合的 offset 行为见官方文档和设计，不冒充站点观测或严格 DST 午夜聚合。

分别通过 get 获取上述 8 个目标的 ID 身份与时区：海淀、德清、昆山、新都 feature_code 均为 PPLA3（行政中心点），不是用北京／湖州／苏州／成都整体代替县区。Open-Meteo 使用坐标网格预报，行政中心点并非县区内所有位置的精确实况。Shinjuku 为 PPLX，按海外数据源可检索细分地点验收。中文语言下 Kunshan/Shinjuku 仍可能为英文名，保留该回退名称；供应商中文结果混有简繁字形，应用不伪造翻译。

8 个目标均分别调用 current 和 daily（不是合并一次请求）：current_units 为 °C、%、m/s、wmo code，time 为 unixtime；daily_units 日期为 iso8601，高低温 °C。7 个目标日期为 11-05…11-11，纽约因当地尚为 11-04，返回 11-04…11-10，均为当地 D…D+6。字段与单位核验通过；这不是午夜前后连续实测，任务 1.3 保留未完成。

故意传 latitude=999 的真实请求返回 HTTP 400、error=true、reason 字段；应用不向用户展示该原始 reason。客户端编解码／坏 JSON／重试／取消／配额由合成 HTTPS MockWebServer 测试验证，未通过耗尽真实公共配额来制造 429。

ID 合并与英文界面中文输入补查由仓储测试覆盖；Android 设备拼音转换验证海淀区→海淀→haidian、昆山→kunshan。大范围同名查询存在 50 条上限，用户可增加行政区限定；不据此宣称覆盖中国所有县区。

## 使用条件与未完成门槛

依据 [官方使用条件](https://open-meteo.com/en/terms) 和 [定价](https://open-meteo.com/en/pricing)：免费公共端点限非商业用途，公布限额为 600 次／分钟、5,000 次／小时、10,000 次／日，并有月调用预算（官方当前标示 300,000 次／月）。变量／时间范围可能影响调用折算；本项目当前用于开发验证，不包含商业发布。

大陆宽带、大陆移动、海外实际网络各十次流程及延迟门槛均未验证。当前没有运营商与区域证据，不能用本机成功冒充三地验收。完整 API 24 / target API 设备验收也仍待执行。

来源要求：天气提供 Open-Meteo 与 CC BY 4.0，地理搜索提供 Open-Meteo Geocoding 与 GeoNames。无需天气环境变量，local.properties 仅需 Android SDK 等本机工具链配置。


## 当前供应商结论与调用预算

接口、单位、8 个代表地点的普通日期窗口、无凭据接入与归因通过本机验证；中国所有县区覆盖、真实午夜连续窗口及三类实际网络性能尚未验收。现有证据支持继续使用用户选定的 Open-Meteo，没有引入后端或擅自更换供应商；后续门槛失败时应先记录证据并修订规划。

一次无重试流程通常为 1–3 次 Geo 查询 + 当前天气 1 次 + daily 1 次，共 3–5 个 HTTP 请求。只有网络／超时／5xx 可以重试一次，最多 6–10 次；页面旋转、新鲜数据恢复和相同搜索不会额外调用，语言译名更新另算一次 get。重试与并发仍受 45 秒整体预算和共享 429 冷却约束。

API 35 模拟器运行真实生产组装完成 London→英国目标→天气，截图为 `screenshots/live-london.png` 与 `screenshots/live-london-forecast.png`：当前 9.6°C、70%、4.3m/s，今日预报 10.7/9°C，11-05…11-11 的七日概况，成功获取时间以 London 时区显示。此时设备状态栏为上海时间，地点时间没有跟随设备替换。该样本是人工指定公开地点；不是当前设备位置，不用于地区性能门槛。
