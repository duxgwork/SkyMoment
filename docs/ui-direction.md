# 页面视觉方向

2026-11-06 恢复首页右上角“切换”按钮，点击进入独立搜索页；首页不内嵌搜索输入和候选列表。使用 XML + ViewBinding，浅灰页面背景、白色圆角卡片、深灰文字及低饱和搜索图标；当前温度左对齐，七日列表采用紧凑行。

## 当前页面结构

1. 首页右上角保留“切换”按钮，加载、空态和天气展示期间始终可用；点击进入独立搜索页，选择后更新原首页，取消保留原地点。首页不放置搜索框或候选列表。
2. 当前天气卡片：地点名与行政路径、当前温度和概况、今日预报高低温、湿度和风速。
3. 24 小时预报卡片：横向滑动查看当前小时至未来 23 小时的时间、天气图标、概况和温度，当前小时标注“当前”，跨天显示日期。
4. 七日卡片：今天／星期、日期、天气图标与每天一个概况、高低温；局部失败和不完整提示仍可重试。

独立搜索页沿用迁移前首页搜索区域的样式：浅灰背景、16dp 页面边距、56dp 高白色圆角输入框、左侧搜索图标、右侧清空图标及白色候选卡片。左上角提供 48dp 触控区域的返回箭头，行为与系统返回一致。候选列表使用页面剩余空间；输入为空时，有历史则在搜索框下显示“历史搜索”、清空按钮和白色圆角标签，无历史则不显示历史区域。标签自动换行，最多 10 条，较长记录省略显示且历史区域可以滚动；开始查询时隐藏历史，显示候选或请求状态。不显示天气卡片、品牌标题、副标题或大搜索按钮。

首页与搜索页使用透明系统栏，背景铺满屏幕；正文保留安全边距，首页正文与搜索页左上角返回避让状态栏和刘海，搜索内容避让软键盘。Android 7 无深色导航按钮，底部保留深色导航栏以保证可见。

首次启动显示完整的浅色加载界面：居中的日光与云插画、阶段标题、简短说明、细线不定进度动画，以及“确认位置 → 获取天气”步骤。阶段只根据真实请求更新，定位完成后显示勾选状态，不模拟百分比；小屏可滚动。成功后显示天气，并异步把“当前位置”更新为解析到的区县／城市名称；解析失败保留当前展示。拒绝权限、定位失败／超时、当前天气失败或为空时，使用独立空态替换整张占位天气卡片：浅灰背景上居中显示云与定位图标、原因标题、简短说明、设置或重试操作。权限未开启时进入应用设置；定位或天气失败时支持重新尝试。空态可滚动以适应小屏。手动选定地点后，所有天气区域均无可用数据时也展示同款空态；有部分数据时保留天气内容和各区域重试。从首页打开的搜索页通过结果契约返回地点并更新原首页，取消保留已有天气；独立路由访问时继续通过首页路由展示地点。切换期间暂停自动启动请求，避免迟到结果覆盖选择。已有天气中的缺失字段仍统一使用 `WeatherPresentation.MISSING_VALUE`，显示为 `--`。

按用户红框删除“所选地点”标签、全页 Refresh 按钮、七日卡片底部获取时间和天气来源／CC BY 页脚。当前天气的“获取于”时间和搜索结果下方的来源文字也已移除，并收起相应空间；来源信息保留在 README 和数据契约中。天气／降水／风速三段切换控件仍不添加。

预报按所选地点的时区展示，24 小时预报在整点和跨小时回到前台时更新；缺失时段保留位置并显示 `--`。所有真实数值来自 Open-Meteo，参考图片中的地点或温度不写入运行时。
