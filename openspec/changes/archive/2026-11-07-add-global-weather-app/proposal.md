# Proposal

## Why

SkyMoment 面向中国大陆和海外用户提供无需登录的天气查询，让用户选择地点后查看当前天气及包含当地今天的七日预报。用户已确认改用 Open-Meteo 公共 API，消除开发者 API Key 与账户专属 Host 的配置要求，同时保留清晰的组件边界。

## What Changes

- 首次启动进入天气首页，顶部输入与候选列表、下方当前天气及七日预报同屏；未选择地点时显示引导，选择后原地更新天气。
- 支持中文和英文地点搜索：中国支持县、县级市和区，海外按数据源可检索行政区域展示。针对中文别名缺口补充行政后缀规范化和拼音查询，不自动选择或冒充县区结果。
- 搜索页保留最多十条用户主动使用的关键词，以应用私有 MMKV 持久化，支持去重、最近使用置顶与清空；地点对象、坐标和天气仍只保留在内存。
- 显示当前温度、湿度、风速、天气概况、今日预报高低温及获取时间；高低温与七日预报今天一行同源。
- 显示所选地点当地今天起七个日历日，每天一个天气概况及高低温。用户已确认取消分别展示日间／夜间天气。
- 支持加载、空数据、错误、局部成功、刷新失败保留有效数据、当地跨日和系统语言变化。
- Android 使用 Kotlin、XML Views + ViewBinding、MVVM、StateFlow、Retrofit/OkHttp、协程及 ARouter，按基础设施、数据和业务拆分八个 Gradle 模块。
- 简体中文、繁体中文、英文界面，其他系统语言回退英文。天气代码由应用本地化；地点译名使用供应商支持的语言及有效回退名称。
- 直连 Open-Meteo Forecast 和 Geocoding 公共 HTTPS 端点，无 Key、账户专属 Host、签名鉴权头或后端。采用免费非商业端点开展开发与验证，明确来源和服务配额。
- 按最新参考图改为浅灰背景、白色圆角卡片、左对齐大温度和紧凑七日列表。移除所选地点标签、全页刷新按钮、预报获取时间和天气来源页脚；保留当前天气获取时间、独立错误重试与搜索结果来源链接。天气／降水／风速切换控件仍不添加。

范围外：用户账户、后端、自动定位及定位权限、地点收藏、离线城市库、持久化天气缓存、小时预报界面、空气质量、预警、推送、桌面组件、手动语言／单位设置、多天气源自动切换、商业发布和应用商店发布。所有语言统一 °C、m/s、%。

## Capabilities

### New Capabilities

- `location-search`：匿名进入、全球地点搜索、县区粒度、重名辨识、选择和切换地点，以及 MMKV 搜索词历史与清空。
- `current-weather`：当前天气指标、今日高低温、获取时间，以及独立刷新状态。
- `seven-day-forecast`：地点当地今天起的七日概况、高低温、日期完整性与跨日更新。
- `weather-data-access`：公共端点、错误分类、请求生命周期、数据校验及真实服务验收。
- `system-localization`：系统语言映射、地点译名回退、天气代码翻译与日期数字格式。

### Modified Capabilities

无。当前主规格目录尚无已归档能力。

## Impact

- 搜索历史由 `Datalayer` 的 `MmkvSearchHistoryRepository` 实现，宿主通过既有 `SearchHistoryRepository` 契约装配；MMKV 依赖固定为 `com.tencent:mmkv:1.3.17`，不增加生产模块依赖边。真实 JNI 与文件读写由 `Datalayer/src/androidTest` 验证，业务查询继续使用本地单元测试。
- 保留已实现的八模块、XML 页面、ViewModelFactory、StateFlow、ARouter、内存会话和基础三语资源；数据实现、来源文案和后续测试改为 Open-Meteo 契约。
- compileSdk 37、minSdk 24、targetSdk 36；沿用已验证的 AGP 9.3.3 / Gradle 9.5.0 / JDK 21，不因供应商切换改变工具链。
- 不再需要环境凭据注入或凭据轮换。发布构建仍验证固定公共端点与网络策略，但不以缺少 Key 为失败条件。
- 文档核验日期为 2026-11-05。依据 [天气文档](https://open-meteo.com/en/docs)、[地理搜索文档](https://open-meteo.com/en/docs/geocoding-api) 及 [使用条件](https://open-meteo.com/en/terms)。公共端点免费非商业使用有调用限额；不把免 Key 等同于无限使用或商业授权。
- 已完成本机无 Key 天气冒烟及部分搜索样本，尚不能据此宣称所有县区覆盖或大陆／海外网络验收通过。
