# Spec Delta

## Purpose

让中国大陆和海外用户按系统语言自然使用天气查询，首版提供简体中文、繁体中文及英文界面，并对语言回退、供应商文本、日期格式及运行中语言变化规定一致行为，使搜索和天气结果不会因系统设置变化而混用错误语言。

## ADDED Requirements

### Requirement: 跟随系统的三语界面
应用 SHALL 根据系统首选语言自动选择简体中文、繁体中文或英文；非中文且非英文时回退英文。中文有明确 Hans/Hant 脚本时以脚本为准；无脚本时 TW、HK、MO 使用繁体，其余中文使用简体。首版不提供应用内语言选择设置。

#### Scenario: 常用系统语言
- **WHEN** 系统首选语言分别为 zh-CN、zh-TW、zh-HK、en-US 或 fr-FR
- **THEN** 界面分别为简体中文、繁体中文、繁体中文、英文或英文

#### Scenario: 脚本优先
- **WHEN** 系统首选语言为 zh-Hant-CN 或 zh-Hans-HK
- **THEN** 分别使用繁体中文或简体中文，不仅依据地区代码判定

### Requirement: 界面文案与 API 语言一致
应用 SHALL 本地化标题、操作、状态、错误、指标标签及来源文案，并在搜索和天气请求中显式携带与界面对应的语言：简体为 zh-hans、繁体为 zh-hant、英文为 en。供应商缺少译名时保留其有效回退名称，不编造译名；缺少天气文字时使用可用的本地化天气代码映射或未知天气文案。

#### Scenario: 中文系统查询海外地点
- **WHEN** 中文界面的用户查询纽约
- **THEN** 请求明确指定中文语言，页面自身文案为中文；供应商仅提供英文地点名称时可保留英文名称

#### Scenario: 错误提示
- **WHEN** 英文界面发生网络错误或返回空数据
- **THEN** 错误、空状态和重试按钮均为英文，不直接展示原始供应商错误字符串

### Requirement: 日期数字和计量单位
应用 SHALL 按当前有效界面语言格式化日期、星期、数值和状态文字；时区始终使用所选地点的时区。首版所有语言均明确使用 °C、m/s 和 %，不根据语言自动切换到华氏或英里；数字格式化不得改变网络请求坐标格式。

#### Scenario: 英文查看中国天气
- **WHEN** 英文界面的用户查看中国县区
- **THEN** 日期和星期使用英文，今天按该县区当地日期确定，温度和风速仍显示 °C 与 m/s

### Requirement: 运行中语言变化
应用 SHALL 在系统语言变化后更新界面资源，取消或忽略旧语言请求并重新获取当前查询或已选地点的本地化数据。语言切换加载期间不得把旧语言天气描述当成新语言请求的结果；若刷新失败，可显示无旧语言描述的已有数值及本地化错误提示。

#### Scenario: 请求期间切换语言
- **WHEN** 中文天气请求尚未完成，系统改为英文并恢复应用
- **THEN** 页面使用英文文案并发起英文请求，迟到的中文结果不能覆盖英文页面状态

#### Scenario: 切换语言时离线
- **WHEN** 已显示天气时系统语言改变且网络不可用
- **THEN** 标题等界面文案及时切换，仍可保留数值和原获取时间，旧天气描述隐藏或由本地代码翻译，显示新语言的刷新失败提示
