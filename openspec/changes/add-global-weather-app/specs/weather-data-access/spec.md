# Spec Delta

## Purpose

为匿名天气查询提供无需开发者凭据的公共数据接入，约束错误、重试、数值、日期、来源及隐私语义，并通过真实地点样本和大陆海外网络验证判断服务可用性，避免把免 Key、文档支持或单机成功误当作完整覆盖保证。

## ADDED Requirements

### Requirement: 主数据源验证与上线前置条件
系统 SHALL 使用 Open-Meteo 公共天气及地理搜索服务。只有县区／海外地点、当前天气、七日窗口、语言行为、使用条件及大陆海外网络验证通过后，才能宣称真实服务验收通过。缺少地区测试环境时 SHALL 保持未验证，失败时记录证据，不擅自替换供应商或缩减县区／七日要求。

#### Scenario: 只有文档或本机冒烟
- **WHEN** 仅确认官方文档或本机几个请求成功
- **THEN** 记录对应的有限结论，不声明所有县区或大陆海外网络已验收

#### Scenario: 实测通过
- **WHEN** 矩阵中的地点、语言、七日日期和三种区域网络均通过，并确认适用使用条件
- **THEN** 记录测试时间、网络区域、参数、非敏感断言及延迟，不将完整地理响应作为持久业务缓存

### Requirement: 无凭据公共直连
系统 SHALL 通过固定公共 HTTPS 端点直接请求，不要求 API Key、账户专属 Host、签名头、开发者账户或用户账户。无凭据的干净检出 SHALL 可以构建 debug/release，并在网络可达时执行查询；不因不存在天气凭据配置而失败，也不连接示例主机。

#### Scenario: 没有天气配置文件
- **WHEN** 工程只有 Android SDK 的必要本机配置，没有天气 Key 或专属 Host
- **THEN** 正常构建并使用公共端点，用户可以直接搜索和查询

#### Scenario: 非预期鉴权响应
- **WHEN** 公共服务返回 401 或 403
- **THEN** 显示本地化服务不可用，不弹出登录／Key 输入，不自动循环重试

### Requirement: 数据结果与错误分类
系统 SHALL 区分成功有数据、成功无数据、地点不支持、网络／超时、额度／限流、服务故障及载荷异常。HTTP 错误不得解释为空结果；包含 error=true 的载荷即使 HTTP 成功也 SHALL 视为失败。缺失可选字段与损坏必要结构 SHALL 区别处理，不直接展示服务 reason 原文。

#### Scenario: 无地点与参数错误
- **WHEN** 地理搜索成功但没有 results，或接口返回 HTTP 400 / error=true
- **THEN** 前者显示无匹配地点，后者显示服务请求失败，不把错误参数当作空地点

#### Scenario: 格式错误
- **WHEN** 天气必需 envelope 缺失、类型错误、JSON 损坏或逐日数组无法可靠对应
- **THEN** 对应区域显示数据异常，其他成功区域继续显示

### Requirement: 有界请求与取消
系统 SHALL 设置有限超时和整体截止；仅临时网络与服务端故障允许有限自动重试。普通参数错误、鉴权响应、配额耗尽和解析错误不自动重试。限流 SHALL 遵守 Retry-After 或本地冷却策略，跨页面共享冷却；取消 SHALL 继续传播，旧查询不能覆盖新查询。

#### Scenario: 持续超时
- **WHEN** 网络持续不可达
- **THEN** 有限尝试后结束加载并显示网络／超时与恢复入口，不无限请求

#### Scenario: 短期限流或日配额
- **WHEN** 服务返回短期限流及等待时间，或明确日配额耗尽
- **THEN** 前者在冷却内禁止重复请求，后者不自动循环重试；均显示本地化说明

### Requirement: 数值与数据归属校验
系统 SHALL 校验响应声明的单位与地点请求归属，保留零值与负温度。相对湿度按 0–100 的百分比读取，风速不得为负；未知单位、非法值和缺字段显示占位，不伪造默认数值。高温小于低温时不得交换后冒充正常。请求坐标不因界面语言使用小数逗号。

#### Scenario: 百分比和零值
- **WHEN** 返回湿度 65、单位 %，温度 0°C、风速 0m/s
- **THEN** 显示 65%、0°C、0m/s，不再次乘以 100 或把零值当缺失

#### Scenario: 损坏字段
- **WHEN** 湿度超过 100、风速为负或温度单位未知
- **THEN** 对应字段不可用，保留其他有效字段并标示部分缺失

### Requirement: 地理信息仅限当前会话
系统 SHALL 只在当前交互会话保留地理信息，不建立持久搜索历史、地理响应缓存、离线城市索引或包含地点／坐标的日志。首版天气也不落盘；已有数据可在同地点刷新时暂存并显示原获取时间。

#### Scenario: 进程结束
- **WHEN** 搜索后应用进程结束
- **THEN** 磁盘、备份、崩溃附件和 HTTP 缓存中没有本次地理结果，重新进入需要重新选择

### Requirement: 来源与使用条件
天气页面 SHALL 按用户要求移除来源页脚；README 和数据契约 SHALL 保留 Open-Meteo 及 CC BY 4.0 归因。搜索候选展示 SHALL 提供 Open-Meteo Geocoding、GeoNames 及适用的数据归因链接。开发说明 SHALL 明确公共服务的免费非商业用途与调用限额，不宣称无限免费或已有商业授权。

#### Scenario: 查看来源
- **WHEN** 用户查看地点候选或项目数据说明
- **THEN** 可以打开对应数据来源；天气页面的简化不删除项目数据归因
