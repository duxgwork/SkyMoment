# Tasks

以下均为后续实施任务，本轮不执行、不勾选。按组推进；1 为供应商确认，2 为工具链和组件基础，3 为数据层，4–6 为业务与语言行为，7 为跨组件验收。第 1 组缺少真实凭据或网络环境时记录未验证，不宣称集成通过；可以推进不依赖该结果的工程基础，但不能跳过验收。各组测试随对应实现交付。

## 1. 和风天气真实可行性验证

- [ ] 1.1 配置用于验证的账户专属 API Host 和独立开发 API Key，核对 Geo/current/daily 授权、API/应用限制、当前额度及 2027 年 API Key 限制；验证三个接口均可鉴权访问，将非敏感结论记入 `docs/qweather-validation.md`，不把 Key 写入命令历史或仓库。
- [ ] 1.2 按设计矩阵实测海淀、德清、昆山、朝阳及 London/New York/Tokyo/Shinjuku 的三语搜索；逐项验证行政归属、重名辨识及海外细分区域的可用/不可用结论，记录断言摘要而不保存 GeoAPI 响应。
- [ ] 1.3 对选定地点调用 Weather v1 current/daily，验证纬度/经度顺序、数值单位、比例湿度、归因及 D…D+6；补测地点当地午夜前后日期覆盖，记录与 v7 差异和当前时间字段限制，只有真实七日窗口符合规格才通过。
- [ ] 1.4 在大陆宽带、移动网络及至少一处海外实际网络各执行 10 次搜索到天气流程，验证每种网络至少 9 次在 10 秒内完成并记录运营商/区域、时间、延迟、故障；无环境的项保持未验证，阻塞真实服务验收。
- [ ] 1.5 汇总供应商通过/未通过结论、配额使用估算、来源展示与地理数据使用约束；核对验证文档覆盖设计矩阵全部条目，失败时给出具体阻塞证据及所需规划修订，不擅自改供应商或加入后端。

## 3. 网络、数据契约与领域规则

- [ ] 3.1 在 core:network 接入 Retrofit、OkHttp 和 kotlinx.serialization，配置 HTTPS Host、超时、Gzip 与不落盘策略；用 MockWebServer 验证请求编码、压缩响应处理及无重复解压，发布配置不得允许明文地址。
- [ ] 3.2 完成环境凭据注入、请求头脱敏及 Android 包名/证书头配置；验证缺配置 release 构建失败、debug 显示配置错误，捕获测试日志确认无 Key/查询地点/坐标；在配置文档记录 APK Key 可提取及撤销轮换步骤。
- [ ] 3.3 定义 GeoAPI 与 Weather v1 的独立 DTO、数据服务和领域映射，完成 ID、行政路径、坐标精度及时区解析；用合成夹具验证中国/海外地点、纬经顺序、未知附加字段和非法时区处理。
- [ ] 3.4 完成温度、湿度、风速、高低温、天气描述与归因转换；用映射测试验证 0、负温度、0.65→65%、未知单位、负风速、缺字段及高低温异常，不把损坏 envelope 解析为成功空对象。
- [ ] 3.5 实现 HTTP/Geo 业务码/v1 problem 错误分类和统一重试层；用 MockWebServer 验证合法无数据、400 不同错误类型、401/403、404、429 冷却与月度配额、5xx、超时、非法 JSON 和取消，断言自动重试上限及 45 秒整体截止。
- [ ] 3.6 实现可注入 Clock 的七日日历窗口、预报区间映射与完整性校验；以固定时间测试纽约/北京异日、夏令时、午夜、乱序、重复冲突、缺日和无有效日，确认 D…D+6 与今日高低温同源。
- [ ] 3.7 实现搜索/天气仓储及仅内存的地点会话 token，当前天气和预报独立返回结果；用仓储测试验证局部成功、token 失效、无磁盘 Geo 缓存和数据归属，更新数据契约文档并对照真实验证结果核对。

## 4. 地点搜索与导航流程

- [ ] 4.1 实现 SearchViewModel 的只读 StateFlow、输入归一化、350ms 防抖、去重及主动提交；用协程虚拟时间测试空输入、单个中文字符、重复提交、旧请求晚返回和清空输入不会恢复旧结果。
- [ ] 4.2 用 XML/ViewBinding 实现搜索页面五种状态、RecyclerView/ListAdapter 行政路径列表和可点击来源，通过 repeatOnLifecycle 收集 StateFlow 并支持本地化失败重试；用 Espresso/RecyclerViewActions 验证重名辨识、没有默认选择第一条、空数据和网络错误不同，输入框回写不触发重复搜索。
- [ ] 4.3 接通显式地点选择、会话 token 和 ARouter 天气入口，天气页可返回搜索切换地点；用导航测试验证两次选择不会混用地点、返回栈不重复堆积，失效 token 和进程重建回到搜索。
- [ ] 4.4 完成启动入口与 Manifest 所需 INTERNET 配置，不引入定位权限或账户入口；在设备上验证首次启动直达搜索、拒绝所有非必要权限仍可完成查询，将搜索流程及会话不持久化行为写入使用说明。

- [ ] 5.2 用 XML/ViewBinding 实现当前天气、今日预报高低温、单位、获取时间与归因 UI，通过 repeatOnLifecycle 收集 StateFlow 并幂等渲染；用 Espresso 测试验证零值、缺失占位、无今日预报、未知图标以及“获取于”不会误标观测时间，并确认高低温与预报今天一行一致。

- [ ] 5.4 实现全页刷新、失败区域重试、刷新保留旧数据及限流冷却反馈；验证重复点击只产生一组在途请求、失败保留原获取时间、冷却未到不发新请求，成功后清除对应错误。
